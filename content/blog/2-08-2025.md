# Why we use ?
For Developing,shipping and running application. It seperate application from infrastructure.
Docker provides ability to run application in losely isolated envirnment called container. Container are light weight and contain every thing needed to run an application independent of host.
Reasons to use container 
- Portability : It can run anywhere irrespective of OS and hardware platform
- Consistency : operate in same way regardless where they are deployed
- speed of deploy : No need to worry whether application may break in production envirnment

 virtual machine instance needs an entire operating system to be in place and running, which adds a lot of overhead and increases the number of variables that need to be managed between what a developer builds and what is running in production. 
 a container only needs a single instance of an operating system in place so it can run more instances on the same servers.
